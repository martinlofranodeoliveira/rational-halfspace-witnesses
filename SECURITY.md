# Security

This is development version 0.1.0, not a production constraint service. No support-time guarantee or response SLA is offered.

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/martinlofranodeoliveira/rational-halfspace-witnesses/security/advisories/new). Use only synthetic reproductions; do not include credentials, private client data or real personal data. General contact: [Lofrano Tecnologia](https://lofranotecnologia.com.br).

The CLI bounds retained stdin before parsing, validates a small schema, uses checked exact arithmetic and verifies proposed evidence. It does not execute caller-supplied commands, read caller-selected paths or use runtime network APIs. Native Z3 is test-only. Typed Haskell callers already execute code in the same process; preallocated hostile values, infinite lists and arbitrary caller code are not sandboxed.

Resource bounds are algorithmic admission limits, not real-time deadlines. Stalled inherited streams or outer termination are INCOMPLETE. A partial stdout document is not evidence. Require the contract's complete framing and exit status. Run untrusted JSON under independent process/container limits. The supported filesystem is local, controlled and cooperative, without concurrent hostile mutation. No universal descendant cleanup, atomic stdout publication or durability guarantee is made.

Português: relatos de vulnerabilidade devem usar o link privado acima, com exemplos sintéticos. Orçamento esgotado e execução incompleta não significam inviabilidade. Exija saída completa e código correto; use limites externos ao processar JSON não confiável. A biblioteca não é uma barreira contra código Haskell hostil no mesmo processo.
